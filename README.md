# 张馨丹｜产品经理作品集

这是我的个人作品集。我希望它不只是简历的网页版本，而是一条可以被浏览和操作的产品叙事：从经历与教育出发，通过真实案例说明我如何理解问题、设计机制、验证方案，并把结果推进到可用状态。

在线访问：[onepage-eggz.pages.dev](https://onepage-eggz.pages.dev)

## 网站内容

- **经历路径**：记录我在小红书、百度、中航成飞研究所和作业帮的实践，以及这些经历如何共同形成我的产品方法。
- **教育坐标**：介绍我在电子科技大学和南京航空航天大学的交叉学科背景。
- **案例橱窗**：展示 Agent 人机协作、旅游搜索引擎和智慧学工系统三个不同维度的案例；AI 案例内包含信息补全、操作确认和产物预览原型。
- **项目选集**：补充摄影工作室、客户行为分析和私域运营分析，点击项目可展开角色、交付与能力证据。
- **能力档案**：可以随机抽取或直接选择能力卡，翻面查看来自不同经历和项目的证据，并精确跳转到对应位置。
- **下班以后**：收录我拍摄的旅行、城市与家常料理照片。

## 设计思路

网站采用“暖调编辑室”的视觉语言，以米白、姜黄、霜蓝和深空蓝为主色。不同章节使用不同的信息结构，而不是重复堆叠同一种卡片：经历采用图文交替排版，案例集中在一个互动舞台，能力以可翻转卡组呈现，生活区保留杂志式图片编排。

所有关键交互均支持桌面端和移动端，并为 `prefers-reduced-motion` 提供静态模式。更完整的设计原则与内容边界见 [`DESIGN.md`](./DESIGN.md)。

## 技术实现

- 原生 HTML、CSS 和 JavaScript
- 无框架、无构建依赖
- `IntersectionObserver` 驱动章节状态和进入动效
- 原生可访问 Tab、键盘导航、Lightbox 与卡片交互
- 响应式适配桌面和移动设备

主要页面、样式与交互均位于 [`index.html`](./index.html)，图片素材位于 [`assets/`](./assets/)。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。
